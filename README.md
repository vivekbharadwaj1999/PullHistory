# Pull History

Pull History records FFXIV pulls and replays them with a standalone encounter radar. BossMod Reborn can be disabled.

**[Standalone plugin source and instructions](https://github.com/vivekbharadwaj1999/PullHistory/tree/pull-history-standalone)** · **[Dalamud feed](https://raw.githubusercontent.com/vivekbharadwaj1999/PullHistory/dalamud/repo.json)**

In Dalamud Settings, add the feed as a custom plugin repository. Install **Pull History** and use `/lastpull`. When migrating from the previous development build, disable that copy first.

Standalone development takes place on the `pull-history-standalone` branch. The `dalamud` branch serves verified release packages. The upstream project and licensing notices are available in [BossMod Reborn](https://github.com/FFXIV-CombatReborn/BossmodReborn).
